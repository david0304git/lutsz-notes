01

極限與導數

微分是「變化率」，而變化率要講清楚，得先有極限。

定義 · 極限（limit）

極限描述當 $x$ 趨近某個值時，函數所趨近的值。寫成

$$\lim_{x \to a} f(x) = L$$

意思是：當 $x$ 趨近 $a$ 時，$f(x)$ 趨近 $L$。

例如 $\lim\limits_{x \to 2} (x + 3) = 5$。

從平均變化率到瞬時變化率

函數 $f$ 的斜率（gradient），也就是我們說的變化率（rate of change）：

$$\frac{\Delta y}{\Delta x} = \frac{\Delta f}{\Delta x} = \frac{f(x + h) - f(x)}{h}$$

這是「走一小段」的平均變化率。想知道「某一點的變化率」，就讓這一段縮到 $0$。

EXAMPLE從定義求 $f(x) = x^3$ 的導數

設 $f(x) = x^3$，則 $f(x + h) = (x + h)^3$。先算變化率：

$$\frac{\Delta f}{\Delta x} = \frac{(x + h)^3 - x^3}{h}$$

展開分子：$(x + h)^3 = x^3 + 3x^2h + 3xh^2 + h^3$，於是

$$\frac{\Delta f}{\Delta x} = \frac{x^3 + 3x^2h + 3xh^2 + h^3 - x^3}{h} = 3x^2 + h(3x + h)$$

分子分母同除以 $h$ 之後，$h$ 只出現在第二項——這正是等一下能讓 $h \to 0$ 的關鍵。

讓 $h \to 0$

現在假設 $h$ 很小，並且讓 $h \to 0$（此時 $x + h \to x$）：

$$\lim_{h \to 0} \frac{\Delta f}{\Delta x} = \lim_{h \to 0}\bigl(3x^2 + h(3x + h)\bigr)$$
$$\lim_{h \to 0} \frac{\Delta f}{\Delta x} = \lim_{h \to 0} 3x^2 + \lim_{h \to 0} \bigl(h(3x + h)\bigr)$$
$$\lim_{h \to 0} \frac{\Delta f}{\Delta x} = 3x^2$$

$3x^2$ 與 $h$ 無關，直接留下；$h(3x + h)$ 在 $h \to 0$ 時整項消失。這就是 $x^3$ 的導數是 $3x^2$ 的由來。

定義 · 導數（derivative）

函數 $f$ 的導數定義為

$$f'(x) = \lim_{h \to 0} \frac{f(x + h) - f(x)}{h} = \lim_{\Delta x \to 0} \frac{f(x + \Delta x) - f(x)}{\Delta x}$$

而且當 $\Delta x$ 很小時，

$$f'(x) \approx \frac{\Delta f}{\Delta x}$$

注意：不是每個函數在每一點都可微。本課只處理在討論範圍內可微的函數。

02

冪函數法則

最常用的一條法則——只要會降次，就能微分一大堆東西。

法則 · 冪函數（power function rule）

若 $f(x) = x^{k}$，則

$$f'(x) = kx^{k-1}$$
EXAMPLE最基本的一次

設 $f(x) = x$，也就是 $f(x) = x^{1}$，套用法則（$k = 1$）：

$$f'(x) = 1 \cdot x^{1-1} = x^{0} = 1$$

斜率處處是 $1$——和直線 $y = x$ 的圖形一致。

EXAMPLE負次方：$f(x) = 8000x^{-3}$

$$f'(x) = 8000(-3)x^{-3-1} = -24000x^{-4} = -\frac{24000}{x^{4}}$$

負次方照樣「降次」：$-3$ 乘下去，次方變成 $-4$。

經濟應用 · 價格變動對銷售量的影響

假設需求函數為

$$q_D(p) = 8000p^{-3}$$

其中數量 $q$ 以千單位計。若價格由 20 漲到 21，預期銷售量會掉多少？

先微分（冪函數法則）：

$$q_D'(p) = 8000(-3)p^{-3-1} = -24000p^{-4} = -\frac{24000}{p^{4}}$$

再用 $\Delta q \approx q_D'(p)\,\Delta p$，取 $p = 20$、$\Delta p = 1$：

$$\Delta q \approx -\frac{24000}{p^{4}}\,\Delta p = -\frac{24000}{20^{4}}(1) = -0.15$$

所以預期會少賣 $0.15 \times 1000 = \mathbf{150}$ 單位。

經濟應用 · 增產對價格的影響（反需求函數）

反過來問：若產量由 1,000 單位增加到 1,100 單位，價格會跌多少？

這就要把函數改寫，把 $p$ 看成 $q$ 的函數：

$$p^{D}(q) = \left(\frac{8000}{q}\right)^{1/3} = \frac{8000^{1/3}}{q^{1/3}} = 20q^{-1/3}$$

微分（冪次 $-1/3$ 降成 $-4/3$）：

$$p^{D\prime}(q) = 20\left(-\frac{1}{3}\right)q^{-\frac{1}{3}-1} = -\frac{20}{3}q^{-4/3}$$

取 $q = 1$、$\Delta q = 0.1$（單位是千），得

$$\Delta p \approx -\frac{20}{3}q^{-4/3}\Delta q = -\frac{20}{3}(1)^{-4/3}(0.1) = -\frac{2}{3}$$

預期價格下跌約 67 分。

03

和法則與常數法則

多項式之所以好微分，就是靠這兩條。

法則 · 和法則（sum rule）

若 $h(x) = f(x) + g(x)$，則

$$h'(x) = f'(x) + g'(x)$$

逐項微分即可，減法同理。

EXAMPLE三項多項式

$$h(x) = 6x^{3} + 3x^{2} + x$$

$$h'(x) = 6(3)x^{3-1} + 3(2)x^{2-1} + x^{1-1} = 18x^{2} + 6x + 1$$
EXAMPLE兩項多項式

$$h(x) = 2x^{8} - 3x^{6}$$

$$h'(x) = 2(8)x^{8-1} - 3(6)x^{6-1} = 16x^{7} - 18x^{5}$$
法則 · 常數法則（constant rule）

若 $f(x) = k$ 且 $k \in \mathbb{R}$（常數），則

$$f'(x) = 0$$

常數的圖形是水平線，斜率當然是 $0$。推論：加上常數不影響導數，因為 $k' = 0$。

EXAMPLE分數次方＋常數

$$f(x) = 8x^{1/4} + 6$$

$$f'(x) = 8\left(\frac{1}{4}\right)x^{\frac{1}{4}-1} + 0 = 2x^{-3/4} = \frac{2}{\sqrt[4]{x^{3}}}$$

常數 $6$ 微分成 $0$；係數 $8$ 乘上冪次 $\frac{1}{4}$ 得 $2$。

04

乘積法則

兩個函數相乘，不能「各自微分再相乘」——要先輪流微分。

法則 · 乘積法則（product rule）

若 $h(x) = f(x)\,g(x)$，則

$$h'(x) = f(x)g'(x) + g(x)f'(x)$$

口訣：第一個不動、微分第二個；第二個不動、微分第一個，兩項相加。

EXAMPLE兩次方的乘積

$$h(x) = x^{2}\,(x^{6})$$

$$h'(x) = x^{2}\,(6x^{5}) + x^{6}\,(2x) = 6x^{7} + 2x^{7} = 8x^{7}$$

檢查：$x^{2} \cdot x^{6} = x^{8}$，直接微分也是 $8x^{7}$，答案一致。

EXAMPLE兩個括號相乘

$$h(x) = (x^{3} + 1)(x^{2} + 5x)$$

$$h'(x) = (x^{3} + 1)(2x + 5) + (x^{2} + 5x)(3x^{2})$$
$$h'(x) = 5x^{4} + 20x^{3} + 2x + 5$$
證明 · 乘積法則

從導數定義出發：

$$(fg)'(x) = \lim_{h \to 0} \frac{f(x + h)g(x + h) - f(x)g(x)}{h}$$

關鍵技巧是在分子加一項再減同一項（加減 $f(x+h)g(x)$）：

$$= \lim_{h \to 0} \frac{f(x + h)g(x + h) - f(x + h)g(x) + f(x + h)g(x) - f(x)g(x)}{h}$$

把前兩項、後兩項各自提出公因式：

$$= \lim_{h \to 0} \frac{f(x + h)\bigl[g(x + h) - g(x)\bigr] + g(x)\bigl[f(x + h) - f(x)\bigr]}{h}$$

拆成兩個極限，並把與 $h$ 無關的 $f(x+h) \to f(x)$、$g(x)$ 提出來：

$$= f(x)\lim_{h \to 0} \frac{g(x + h) - g(x)}{h} + g(x)\lim_{h \to 0} \frac{f(x + h) - f(x)}{h}$$
$$= f(x)g'(x) + g(x)f'(x)$$
05

商法則

分母不動、分子要減——次序不能顛倒。

法則 · 商法則（quotient rule）

若 $h(x) = f(x)/g(x)$ 且 $g(x) \neq 0$，則

$$h'(x) = \frac{f'(x)g(x) - f(x)g'(x)}{[g(x)]^{2}}$$

口訣：分母平方分之「上微下不微，減上不微下微」。分子減法的次序與正負號是常見錯誤來源。

EXAMPLE兩個冪相除

$$h(x) = \frac{x^{6}}{x^{4}}$$

$$h'(x) = \frac{6x^{5}(x^{4}) - x^{6}(4x^{3})}{(x^{4})^{2}} = \frac{6x^{9} - 4x^{9}}{x^{8}} = \frac{2x^{9}}{x^{8}} = 2x$$

檢查：$x^{6}/x^{4} = x^{2}$，微分得 $2x$，一致。

證明 · 商法則

同樣從定義開始：

$$\left(\frac{f}{g}\right)'(x) = \lim_{h \to 0} \frac{\dfrac{f(x + h)}{g(x + h)} - \dfrac{f(x)}{g(x)}}{h}$$

技巧是減一項再加回來（加減 $\dfrac{f(x)}{g(x + h)}$），把兩個分數接起來：

$$= \lim_{h \to 0} \frac{\dfrac{f(x + h)}{g(x + h)} - \dfrac{f(x)}{g(x + h)} + \dfrac{f(x)}{g(x + h)} - \dfrac{f(x)}{g(x)}}{h}$$
$$= \lim_{h \to 0} \frac{\dfrac{1}{g(x + h)}\bigl[f(x + h) - f(x)\bigr] + f(x)\left[\dfrac{1}{g(x + h)} - \dfrac{1}{g(x)}\right]}{h}$$

把後面那組通分：$\dfrac{1}{g(x+h)} - \dfrac{1}{g(x)} = -\dfrac{g(x+h) - g(x)}{g(x+h)g(x)}$，於是

$$= \lim_{h \to 0} \frac{1}{g(x + h)}\cdot\frac{f(x + h) - f(x)}{h} - \frac{f(x)}{g(x + h)g(x)}\cdot\frac{g(x + h) - g(x)}{h}$$

取極限（$g(x+h) \to g(x)$）：

$$= \frac{1}{g(x)}\lim_{h \to 0}\frac{f(x + h) - f(x)}{h} - \frac{f(x)}{[g(x)]^{2}}\lim_{h \to 0}\frac{g(x + h) - g(x)}{h}$$
$$= \frac{f'(x)}{g(x)} - \frac{f(x)g'(x)}{[g(x)]^{2}} = \frac{f'(x)g(x) - f(x)g'(x)}{[g(x)]^{2}}$$
06

連鎖法則（複合函數）

函數裡還有函數時，變化率會「一層一層乘下去」。

假設 $k$ 是一個複合函數 $sr$，也就是 $k(x) = s(r(x))$。

$x$ 的小變化會造成 $r$ 的小變化，而 $r$ 的小變化又造成 $k$ 的小變化。因此

$$\frac{\Delta k}{\Delta x} = \frac{\Delta s}{\Delta x} = \frac{\Delta s}{\Delta r}\cdot\frac{\Delta r}{\Delta x}$$

取極限後得到

$$\frac{dk}{dx} = \frac{ds}{dx} = \frac{ds}{dr}\cdot\frac{dr}{dx}$$
$$k' = sr'(x) = s'\bigl(r(x)\bigr)\,r'(x)$$
法則 · 連鎖法則（chain rule）

若 $k(x) = s\bigl(r(x)\bigr)$，則

$$k'(x) = s'\bigl(r(x)\bigr)\,r'(x)$$

「外層微分（內層原樣放著）乘上內層微分」——由外往內一層一層剝。

EXAMPLE括號平方

$$k(x) = s\bigl(r(x)\bigr) = (5x^{2} + 3x + 7)^{2}$$

拆成內外兩層：$r(x) = 5x^{2} + 3x + 7$，外層 $s(u) = u^{2}$。

$$k'(x) = s'\bigl(r(x)\bigr)r'(x) = 2\bigl(r(x)\bigr)r'(x)$$
$$k'(x) = 2(5x^{2} + 3x + 7)(10x + 3)$$
EXAMPLE在 $x = 1$ 取值

承上，求 $k(x) = (5x^{2} + 3x + 7)^{2}$ 在 $x = 1$ 的導數值。

$$k'(1) = 2\bigl(5(1)^{2} + 3(1) + 7\bigr)\bigl(10(1) + 3\bigr) = 2(15)(13) = 390$$
07

反函數的導數

$f^{-1}$ 的導數，就是 $f'$ 的倒數。

回想反函數的定義：若 $g = f^{-1}$，則 $gf = f^{-1}\bigl(f(x)\bigr) = x = i$，也就是恆等函數。

複合函數的導數就是恆等函數的導數。對 $f^{-1}\bigl(f(x)\bigr) = x$ 的兩邊同時對 $x$ 微分（左邊用連鎖法則）：

$$\bigl(f^{-1}\bigr)'\bigl(f(x)\bigr)f'(x) = 1$$
$$\bigl(f^{-1}\bigr)'\bigl(f(x)\bigr) = \frac{1}{f'(x)}$$

若令 $y = f(x)$、$x = g(y)$，就得到更常用的形式：

法則 · 反函數導數
$$g'(y) = \frac{1}{f'(x)}$$

「反函數的斜率 = 原函數斜率的倒數」——因為把圖形對 $y = x$ 翻過去，上升與前進的角色互換。

EXAMPLE求反函數的導數（並驗算）

設 $f(x) = x^{2} - 5$（$x \geq 0$），求其反函數的導數。

直接套公式：

$$g'(y) = \frac{1}{f'(x)} = \frac{1}{2x}$$

驗算：由 $y = x^{2} - 5$ 解出 $x$，得 $x^{2} = y + 5$，所以

$$x = g(y) = (y + 5)^{1/2}$$
$$g'(y) = \frac{1}{2}(y + 5)^{-1/2} = \frac{1}{2\sqrt{y + 5}} = \frac{1}{2x} = \frac{1}{f'(x)}$$

兩條路得到同一個答案——這也說明為什麼反函數的導數是倒數。

經濟應用 · 供給集與反函數

供給集包含所有滿足供給關係的有序對 $(q, p) \in \mathbb{R}^{2}$：

$$S = \{\,(q, p) \mid 2p - 3q = 12\,\}$$

其中 $p$ 是價格，$q$ 是對應的供給量。供給函數為

$$q^{S}(p) = \frac{2p}{3} - 4$$

反供給函數則是

$$p^{S}(q) = 6 + \frac{3q}{2}$$

顯然 $q^{S}$ 與 $p^{S}$ 的導數分別是 $\dfrac{2}{3}$ 與 $\dfrac{3}{2}$。用反函數公式可以得到同樣的答案：

$$q^{S\prime}(p) = \frac{2}{3} = \frac{1}{p^{S\prime}(q)} = \frac{1}{3/2}$$

兩個導數互為倒數，正是反函數關係的必然結果。

08

高階導數與邊際概念

微分一次得到變化率；再微分一次，得到「變化率的變化率」。

前面談的是 $f$ 的一階導數，現在引入更高階的導數概念：

導數的記號
階數記號念法
一階$f'(x)$ 或 $\dfrac{dy}{dx}$first derivative
二階$f''(x)$ 或 $\dfrac{d^{2}y}{dx^{2}}$second derivative
三階$f'''(x)$ 或 $\dfrac{d^{3}y}{dx^{3}}$third derivative
EXAMPLE逐階微分

$$f(x) = 3x^{3} + 5x^{2} - 6x + 2$$

$$f'(x) = 9x^{2} + 10x - 6$$
$$f''(x) = 18x + 10$$
$$f'''(x) = 18$$

再微分一次就得到 $0$——三次多項式只有前三階導數不為零。

邊際概念就是微分

經濟學經常關心邊際（marginal）概念。假設 $y = f(x)$，當 $x$ 變動 $\Delta x$ 時，$y$ 的對應變動是

$$\Delta y = f(x + \Delta x) - f(x)$$

變化率為 $\Delta y / \Delta x$。當 $\Delta x$ 變得非常小時：

$$\frac{dy}{dx} = f'(x) = \lim_{\Delta x \to 0}\frac{\Delta y}{\Delta x}$$
重點

因此微分可以用來研究各種邊際變化：邊際成本、邊際收入、邊際效用、邊際產量。

09

邊際成本與邊際收入

把「多生產一單位要多花多少錢」寫成導數。

邊際成本（Marginal Cost）

設總成本函數為 $C = C(q)$，其中 $q$ 是生產水準、$C(q)$ 是該生產水準下的總成本。

若產量變動 $\Delta q$，變動後的總成本是 $C(q + \Delta q)$，因此總成本的變動為

$$\Delta C = C(q + \Delta q) - C(q)$$

而「每單位產量變動所造成的成本變動」就是 $\dfrac{\Delta C}{\Delta q}$。當 $\Delta q \to 0$（產量變化極小）：

定義 · 邊際成本
$$MC(q) = C'(q) = \frac{dC}{dq} = \lim_{\Delta q \to 0}\frac{\Delta C}{\Delta q}$$

邊際成本解釋為「多生產一單位產出所增加的成本」。一般而言，$\Delta C$ 與 $\Delta q$ 的關係是

$$\Delta C \approx C'(q)\,\Delta q$$

若產量增加 1 單位（$\Delta q = 1$），則 $\Delta C \approx C'(q) = MC(q)$。

EXAMPLE線性成本：邊際成本等於平均變動成本

某自行車廠每週固定開銷 5 萬元，每生產一輛車的材料與工錢 25 元。成本函數為

$$C(q) = 50000 + 25q$$

5 萬元的開銷是固定成本（fixed cost），與產量 $q$ 無關。

平均變動成本（average variable cost）按定義就是每單位的變動成本，即 25 元。

邊際成本為 $C'(q) = 25$（常數）——和平均變動成本相同。

EXAMPLE二次成本：邊際成本隨產量上升

現在成本函數改為

$$C(q) = 50000 + 25q + 0.001q^{2}$$

邊際成本為

$$C'(q) = 25 + 0.002q$$

若產量由每週 100 提升到每週 10,000，邊際成本會從

$$C'(100) = 25 + 0.002(100) = 25.2$$

上升到

$$C'(10{,}000) = 25 + 0.002(10{,}000) = 45$$

產量越大，多生產一單位越貴——這是二次項 $0.001q^{2}$ 造成的。

從需求曲線到邊際收入（Marginal Revenue）

設某商品的需求集為 $D = \{(q, p) \mid q + bp = a\}$。要求邊際收入，必須先把總收入寫成 $q$ 的函數：

$$R(q) = p(q)\,q$$

其中 $p(q)$ 是反需求函數。把 $q + bp = a$ 移項：

$$p^{D}(q) = \frac{a - q}{b}$$

於是總收入可以寫成

$$R(q) = q\,p^{D}(q) = q\left(\frac{a - q}{b}\right) = \frac{aq}{b} - \frac{q^{2}}{b}$$

微分得到邊際收入：

定義 · 邊際收入
$$MR = R'(q) = \frac{a - 2q}{b}$$

邊際收入就是總收入對 $q$ 的導數。

EXAMPLE獨占廠商的邊際收入

假設 Calculus Corporation 是獨占廠商，需求函數為

$$q = 300 - 20p$$

移項得到反需求函數

$$p^{D}(q) = 15 - \frac{q}{20}$$

因此總收入函數為

$$R = q\,p^{D}(q) = 15q - \frac{q^{2}}{20}$$

邊際收入函數為

$$MR = R'(q) = 15 - \frac{q}{10}$$
10

需求彈性

「漲價會增加還是減少收入？」——答案完全取決於彈性。

設需求函數為 $q = q(p)$，總收入為 $R = qp$。由於 $q$ 取決於 $p$，可寫成 $R(p) = q(p)\,p$。

用乘積法則對 $p$ 微分：

$$R'(p) = q'(p)\,p + q$$

收入增加（$R' > 0$）的條件是 $q'(p)\,p + q > 0$，等價於

$$-\frac{q'(p)\,p}{q} < 1$$
定義 · 需求彈性（elasticity of demand）
$$\varepsilon(p) = -\frac{q'(p)\,p}{q}$$

因此收入對價格的導數可以改寫成

$$R'(p) = q'(p)\,p + q = q\left(\frac{q'(p)\,p}{q} + 1\right) = q\bigl[1 - \varepsilon(p)\bigr]$$
重點 · 彈性與收入
  • $\varepsilon(p) < 1$（缺乏彈性 inelastic）：小幅漲價會使收入增加。
  • $\varepsilon(p) > 1$（富有彈性 elastic）：小幅漲價會使收入減少。
EXAMPLE固定彈性的需求函數

設需求函數為

$$q^{D}(p) = \frac{K}{p^{c}} = Kp^{-c}$$

其中 $K$ 與 $c$ 是正常數。需求彈性為

$$\varepsilon(p) = -\frac{q^{D\prime}(p)\,p}{q} = -\frac{-cKp^{-c-1}\cdot p}{Kp^{-c}} = c$$

彈性是常數。當 $c > 1$ 需求富有彈性，$c < 1$ 則缺乏彈性。

EXAMPLE線性需求：彈性隨價格變動

設需求集為 $D = \{(q, p) \mid q + 5p = 30\}$，其中 $p$ 是價格、$q$ 是對應的需求量。

需求函數為 $q^{D}(p) = 30 - 5p$，因此

$$\varepsilon(p) = -\frac{q^{D\prime}(p)\,p}{q} = -\frac{-5p}{30 - 5p} = \frac{p}{6 - p}$$

在 $p = 6$ 時 $\varepsilon(p)$ 無定義，所以彈性要有經濟意義，必須 $0 \leq p < 6$。

需求富有彈性（$\varepsilon(p) > 1$）的區間：

$$\frac{p}{6 - p} > 1 \;\Rightarrow\; p > 3$$

所以 $3 < p < 6$ 時富有彈性；$0 \leq p < 3$ 時缺乏彈性。

同樣一條需求線，便宜時沒彈性、貴時有彈性——漲價的效果會反過來。

指數函數

成長與複利的標準模型，而 $e^{x}$ 的導數就是它自己。

定義 · 指數函數（exponential function）

指數函數的形式為

$$f(x) = a^{x} \quad \text{for all } x \in \mathbb{R}, \text{ where } a > 0 \text{ and } a \neq 1$$

$a$ 稱為底數（base），$x$ 稱為指數（exponent）。例如 $2^{x}$、$\left(\dfrac{1}{4}\right)^{x}$、$5^{x}$。

  • 每個指數函數都通過 $(0, 1)$，因為 $a^{0} = 1$。
  • 當 $a > 1$：$x$ 增加時 $f(x)$ 快速上升，代表快速成長。
  • 當 $0 < a < 1$：函數快速衰減，$x$ 增加時趨近 $0$，但永遠不碰 $x$ 軸。

指數函數常用來描述連續成長，例如複利、人口成長。

定義 · 自然指數函數
$$e^{x} = \lim_{m \to \infty}\left(1 + \frac{x}{m}\right)^{m}$$

當 $x = 1$：

$$e = \lim_{n \to \infty}\left(1 + \frac{1}{n}\right)^{n} \approx 2.71828$$

自然指數函數有個特殊性質：它的導數等於它自己。

$$\frac{d}{dx}e^{x} = e^{x}$$
證明 · $\dfrac{d}{dx}e^{x} = e^{x}$

令 $y = e^{x}$，則 $\ln y = x$。對 $x$ 微分（用反函數導數的想法）：

$$\frac{d}{dx}e^{x} = \frac{dy}{dx} = \frac{1}{dx/dy} = \frac{1}{1/y} = y = e^{x}$$

中間用到 $\dfrac{d}{dy}\ln y = \dfrac{1}{y}$——下一節會證明這條。

法則 · 廣義指數函數法則

若 $f(x) = e^{g(x)}$，則

$$f'(x) = e^{g(x)}g'(x)$$
EXAMPLE指數上是二次式

$$f(x) = e^{ax^{2} + bx + c}$$

$$f'(x) = (2ax + b)\,e^{ax^{2} + bx + c}$$

外面那一層原樣保留，乘上指數內部的導數。

證明 · 廣義指數函數法則

令 $u = g(x)$，用連鎖法則：

$$\frac{d}{dx}e^{g(x)} = \frac{d}{dx}e^{u} = \frac{d}{du}e^{u}\cdot\frac{du}{dx} = e^{u}\frac{du}{dx} = e^{g(x)}g'(x)$$

對數函數

對數是指數的逆運算，而它的導數是 $\dfrac{1}{x}$。

定義 · 對數函數（logarithmic function）

對數函數是指數函數的反函數。

$$\text{若 } y = a^{x}, \text{ 則 } \log_{a} y = x$$

例如：若 $y = 10^{2}$，則 $\log_{10}10^{2} = 2$；若 $y = 8 = 2^{3}$，則 $\log_{2}8 = 3$。

定義 · 自然對數

以 $e$ 為底的對數稱為自然對數（natural logarithm），是自然指數函數的反函數：

$$\log_{e}x = \ln x$$

若 $y = e^{x}$，則 $x = \ln y$；且對 $x > 0$ 有 $e^{\ln x} = x$。

若 $f(x) = \ln x$，則

$$f'(x) = \frac{1}{x} \quad \text{for } x > 0$$
證明 · 對數函數法則 $f'(x) = \dfrac{1}{x}$

從定義出發：

$$f'(x) = \lim_{h \to 0}\frac{\ln(x + h) - \ln x}{h} = \lim_{h \to 0}\frac{1}{h}\ln\left(\frac{x + h}{x}\right)$$

用對數律 $\ln a - \ln b = \ln\dfrac{a}{b}$。

$$= \lim_{h \to 0}\frac{1}{h}\ln\left(1 + \frac{h}{x}\right) = \frac{1}{x}\lim_{h \to 0}\frac{x}{h}\ln\left(1 + \frac{h}{x}\right)$$

令 $u = \dfrac{x}{h}$，則 $\dfrac{x}{h}\ln\left(1 + \dfrac{h}{x}\right) = u\ln\left(1 + \dfrac{1}{u}\right) = \ln\left(1 + \dfrac{1}{u}\right)^{u}$：

$$f'(x) = \frac{1}{x}\lim_{h \to 0}\ln\left(1 + \frac{1}{u}\right)^{u}$$

當 $h \to 0$ 時 $u \to \infty$，而括號內正是 $e$ 的定義：

$$f'(x) = \frac{1}{x}\ln\left[\lim_{u \to \infty}\left(1 + \frac{1}{u}\right)^{u}\right] = \frac{1}{x}\ln e = \frac{1}{x}$$
法則 · 廣義對數函數法則

若 $f(x) = \ln g(x)$，則

$$f'(x) = \frac{g'(x)}{g(x)} \quad \text{for } x > 0$$
EXAMPLE先化簡再微分

$$f(x) = \ln(8x^{5}) = 5\ln(8x)$$

$$f'(x) = 5\left(\frac{1}{8x}\right)(8) = \frac{5}{x}$$

先把對數拆開（$\ln ab = \ln a + \ln b$、$\ln a^{n} = n\ln a$）通常會讓微分簡單很多。

EXAMPLE乘積的對數

設 $f(x) = \ln\bigl[x(1 - x)^{8}\bigr]$，其中 $0 < x < 1$。先拆：

$$f(x) = \ln x + \ln(1 - x)^{8} = \ln x + 8\ln(1 - x)$$

再逐項微分（第二項用連鎖法則，內層導數是 $-1$）：

$$f'(x) = \frac{1}{x} + \frac{8}{1 - x}(-1) = \frac{1}{x} - \frac{8}{1 - x}$$

通分整理：

$$f'(x) = \frac{1 - x - 8x}{x(1 - x)} = \frac{1 - 9x}{x(1 - x)}$$

分子 $1 - 9x$ 告訴我們：$x < \dfrac{1}{9}$ 時 $f$ 上升，之後開始下降。

證明 · 廣義對數函數法則

令 $u = g(x)$，用連鎖法則：

$$\frac{d}{dx}\ln g(x) = \frac{d}{dx}\ln u = \frac{d}{du}\ln u\cdot\frac{du}{dx} = \frac{1}{u}\cdot\frac{du}{dx} = \frac{1}{g(x)}g'(x)$$
本課重點
  • 導數是極限：$f'(x) = \lim\limits_{h \to 0}\dfrac{f(x+h) - f(x)}{h}$；微小變化下 $f'(x) \approx \dfrac{\Delta f}{\Delta x}$。
  • 四條核心法則：冪函數 $kx^{k-1}$、和法則、乘積法則 $f g' + g f'$、商法則 $\dfrac{f'g - fg'}{g^{2}}$。
  • 連鎖法則 $s'(r(x))\,r'(x)$ 處理複合函數；反函數的導數是倒數 $g'(y) = \dfrac{1}{f'(x)}$。
  • 邊際量就是導數：$MC = C'(q)$、$MR = R'(q)$；$\Delta C \approx C'(q)\Delta q$。
  • 需求彈性 $\varepsilon(p) = -\dfrac{q'(p)p}{q}$；$\varepsilon < 1$ 時漲價增加收入，$\varepsilon > 1$ 時反而減少。
  • 指數與對數：$\dfrac{d}{dx}e^{x} = e^{x}$、$\dfrac{d}{dx}\ln x = \dfrac{1}{x}$；複合版本是 $e^{g}g'$ 與 $\dfrac{g'}{g}$。
