01

為什麼經濟學要用數學

數學是經濟學的語言。經濟理論必須把複雜的現實世界簡化，才能討論；而數學提供了一套精確、可操作的方式，把經濟關係寫成可以推導的形式。

  • 數學是經濟學重要的表達語言，在各個層級的經濟學研究中都是實用工具。
  • 經濟理論是對真實世界的簡化（simplification）——數學幫助我們把這些關係寫成易於處理的形式。

數學模型的三個要素

變數（variables）：實數$p,\; q,\; K,\; L$
關係（relationships）：函數$q_D(p) = a - bp$
例子：價格與數量$p$（物價）、$q$（數量）

$K$、$L$ 分別代表資本（capital）與勞動（labour）等投入要素。

需求函數 $q_D(p) = a - bp$ 就是一個典型例子：它把「價格」與「需求量」這兩個變數之間的關係，寫成一條簡潔的式子。

02

集合（Sets）

從最基本的物件收納開始——後面所有數學概念都建立在集合之上。

定義 · 集合

一個集合（set）是一些物件的收集。集合內的物件稱為該集合的元素（elements）或成員（members）。

集合通常用大寫字母表示，例如 $A$、$B$、$S$、$D$；集合的元素寫在大括號 $\{\;\}$ 之內。

指定一個集合的兩種方法

方法一：列舉法（by enumeration）

把所有元素列出來，順序不拘。

$$A = \{1,\, 2,\, 4,\, 6,\, 7,\, 9\}, \qquad Z = \{1,\, 2,\, 3,\, 4\}$$

方法二：描述法（by description）

描述一個性質，指出哪些物件屬於這個集合。

$$B = \{\,x \mid x \text{ is an even integer}\,\}, \qquad Z = \{\,n \mid n \text{ is a positive whole number less than } 5\,\}$$

所以 $Z = \{1,2,3,4\}$——兩種寫法指的是同一個集合。

屬於與不屬於

若 $x$ 在集合 $A$ 之中（$x$ 是 $A$ 的成員、$x$ 屬於 $A$），寫成 $x \in A$；若不屬於，寫成 $x \notin A$。

$$x \in A \qquad \text{（屬於）} \qquad\qquad x \notin A \qquad \text{（不屬於）}$$
EXAMPLE判斷元素是否屬於集合

設 $X = \{2, 3, 5, 7, 8, 9\}$，$Y = \{1, 4, 5, 7, 9\}$。

2 在 $X$ 之中$2 \in X$
3 不在 $Y$ 之中$3 \notin Y$

有限集、無限集與空集

$A$ 是有限集（finite set）：元素個數有限$A = \{1, 2, 4, 6, 7, 9\}$
$B$ 是無限集（infinite set）：元素個數無限$B = \{\,x \mid x \text{ is an even integer}\,\}$
空集（empty set）$\varnothing$：沒有任何元素$\varnothing = \{\;\}$

子集與相等

定義 · 子集（subset）

若 $A$ 的每一個成員都是 $B$ 的成員，稱 $A$ 是 $B$ 的子集：

$$A \subseteq B \qquad \text{或} \qquad B \supseteq A$$

若 $A \subseteq B$，但 $B$ 之中至少有一個成員不屬於 $A$，稱 $A$ 是 $B$ 的真子集（proper subset）：

$$A \subset B$$
定義 · 集合相等

兩個集合 $A$ 與 $B$ 相等（$A = B$）若且唯若：

$$A \subseteq B \quad \text{且} \quad A \supseteq B$$

也就是說，兩個集合互相包含——它們的元素完全相同。注意元素的順序不重要。

EXAMPLE子集與相等

設 $A = \{1, 2, 3\}$，$B = \{3, 1, 2\}$，$C = \{1, 2, 3, 4, 5, 6\}$。

$A$ 的每個元素都在 $C$ 中，且 $C$ 還有其他元素$A \subset C$
$A$ 與 $B$ 元素完全相同（只是順序不同）$A = B$

聯集（Union）

定義 · 聯集

兩個集合 $A$ 與 $B$ 的聯集，是包含所有「屬於 $A$、屬於 $B$、或同時屬於兩者」的成員的集合：

$$A \cup B = \{\,x \mid x \in A \; \text{or} \; x \in B\,\}$$
EXAMPLE聯集

設 $X = \{2, 3, 5, 7, 8, 9\}$，$Y = \{1, 4, 5, 7, 9\}$，$Z = \{1, 2, 3, 4\}$。

$X$ 與 $Y$ 的所有元素合起來$X \cup Y = \{1, 2, 3, 4, 5, 7, 8, 9\}$
$Y$ 與 $Z$ 的所有元素合起來$Y \cup Z = \{1, 2, 3, 4, 5, 7, 9\}$
$Z$ 的元素都在 $X \cup Y$ 之中$Z \subseteq X \cup Y$

交集（Intersection）

定義 · 交集

兩個集合 $A$ 與 $B$ 的交集，是包含所有「同時屬於 $A$ 且屬於 $B$」的成員的集合：

$$A \cap B = \{\,x \mid x \in A \; \text{and} \; x \in B\,\}$$
EXAMPLE交集

沿用上面的 $X$、$Y$、$Z$。

同時在 $X$ 與 $Y$ 的元素$X \cap Y = \{5, 7, 9\}$
$X \cap Y = \{5,7,9\}$ 與 $Z = \{1,2,3,4\}$ 沒有共同元素$(X \cap Y) \cap Z = \varnothing$
同時在 $Y$ 與 $Z$ 的元素$Y \cap Z = \{1, 4\}$
$X$ 與 $\{1,4\}$ 沒有共同元素$X \cap (Y \cap Z) = \varnothing$
重點速記
  • $\in$ / $\notin$：元素與集合的關係。
  • $\subseteq$ / $\subset$：集合與集合的關係（子集／真子集）。
  • $\cup$ 是「或」（or），$\cap$ 是「且」（and）——括號可省略時就照這個規則讀。
  • $\varnothing$ 是空集，它同時是「沒有元素」的意思，也是任何集合的子集。
03

經濟應用：預算集與策略賽局

集合不只是抽象符號——經濟學裡的「可行選項」本身就是集合。

經濟應用 · 個體經濟學：消費者理論

預算集（budget set）是消費者所有負擔得起的組合所形成的集合：

$$B = \{\,(x_1, x_2, \dots, x_n) \in X \;\big|\; p_1x_1 + p_2x_2 + \dots + p_nx_n \le m\,\}$$

$x_i$ 是第 $i$ 種商品的數量，$p_i$ 是其價格，$m$ 是所得。不等式 $p_1x_1 + \dots + p_nx_n \le m$ 就是「總支出不超過所得」。

經濟應用 · 賽局理論／產業組織

一個策略賽局（strategic game）由三部分組成：

  • 玩家的有限集合：$\{1, 2, 3, \dots, N\}$
  • 每位玩家的策略（行動）集合：
$$s_i \in S_i, \qquad S = (S_1, S_2, \dots, S_N)$$
  • 收益函數的集合：給定每一組策略組合，決定玩家的效用。
04

數系（Numbers）

經濟變數取值於哪些數？先把「數的家族」分清楚。

定義 · 實數 $\mathbb{R}$

實數（real number）是連續數線（實數線，$\mathbb{R}^1$）上的任何一個數。

非負實數：所有大於或等於 0 的實數$\mathbb{R}_+ = \{\,x \mid x \ge 0\,\}$
關係$\mathbb{R}_+ \subset \mathbb{R}$
定義 · 整數 $\mathbb{Z}$

整數（integers）是可以不用分數或小數表示的數：

$$\mathbb{Z} = \{\dots, -3, -2, -1, 0, 1, 2, 3, \dots\}$$
定義 · 自然數 $\mathbb{N}$

自然數（natural numbers）就是正整數：

$$\mathbb{N} = \{1, 2, 3, \dots\}$$
數系一覽
符號名稱包含經濟例子
$\mathbb{N}$自然數$1, 2, 3, \dots$員工人數
$\mathbb{Z}$整數$\dots, -2, -1, 0, 1, 2, \dots$淨出口、損益
$\mathbb{R}_+$非負實數$x \ge 0$價格、數量
$\mathbb{R}$實數整條數線利率、成長率
05

有序對（Ordered Pairs）

$(x, y)$ 和 $(y, x)$ 不是同一件事——順序本身就是資訊。

定義 · 有序對

有序對（ordered pair）是兩個元素之間帶有特定次序關係的一對。一般而言：

$$(x, y) \neq (y, x)$$

例如第一象限（first quadrant）可以寫成：

$$\mathbb{R}_{++}^{2} = \mathbb{R}_{++} \times \mathbb{R}_{++} = \{\,(x,y) \in \mathbb{R}^2 \mid x > 0,\; y > 0\,\}$$

笛卡兒乘積與 $\mathbb{R}^2$、$\mathbb{R}^3$

定義 · 笛卡兒乘積
$$\mathbb{R}^2 = \mathbb{R} \times \mathbb{R} = \{\,(x, y) \mid x \in \mathbb{R},\; y \in \mathbb{R}\,\}$$
$$\mathbb{R}^3 = \mathbb{R} \times \mathbb{R} \times \mathbb{R} = \{\,(x, y, z) \mid x \in \mathbb{R},\; y \in \mathbb{R},\; z \in \mathbb{R}\,\}$$

$\mathbb{R}^2$ 就是整個平面（每個點用兩個座標定位）；$\mathbb{R}^3$ 就是三維空間。

EXAMPLE求 $A \times B$

設 $A = \{1, 2\}$，$B = \{a, b, c\}$。則

$$A \times B = \{\,(x, y) \mid x \in A,\; y \in B\,\}$$
$$A \times B = \{(1,a),\; (1,b),\; (1,c),\; (2,a),\; (2,b),\; (2,c)\}$$

注意 $A \times B$ 共有 $2 \times 3 = 6$ 個有序對——每個 $A$ 的元素都要配對每一個 $B$ 的元素。

06

經濟應用：供需與市場均衡

需求表、需求函數、供給函數與均衡——全部用有序對與集合的語言寫出來。

需求表當作有序對的集合

一張需求表可以表示成 $\mathbb{R}^2$ 中的一組有序對：

$$D = \{\,(q_1, p_1),\; (q_2, p_2),\; \dots,\; (q_n, p_n)\,\}$$

其中 $p_i$ 是價格，$q_i$ 是對應的需求量（quantity demanded）。

需求集與需求函數

經濟應用 · 需求集

需求集包含所有在 $\mathbb{R}^2$ 中滿足需求關係的有序對 $(q, p)$：

$$D = \{\,(q, p) \mid 6q + 8p = 125\,\}$$

例如 $(7.5,\; 10) \in D$：當價格是 10 的時候，需求量是 7.5。

由需求集推導需求函數

把 $6q + 8p = 125$ 對 $q$ 移項：

$$q = \frac{125}{6} - \frac{8p}{6} = \frac{125}{6} - \frac{4p}{3}$$

因此需求函數為

$$q_D(p) = \frac{125}{6} - \frac{4p}{3}$$
經濟應用 · 供給集與供給函數

供給集包含所有滿足供給關係的有序對 $(q, p)$：

$$S = \{\,(q, p) \mid 2q - 5p = -12\,\}$$

對 $q$ 移項，得供給函數：

$$q_S(p) = \frac{5p}{2} - 6$$

市場均衡

定義 · 均衡集

均衡集是需求集與供給集的交集：

$$E = S \cap D$$

位於均衡集之中的有序對 $(q^{*}, p^{*})$ 必須同時屬於 $S$ 與 $D$，因此 $q^{*}, p^{*}$ 必須同時滿足兩條方程式。

把兩條方程式並列：

$$q_S(p) = \frac{5p}{2} - 6, \qquad\qquad q_D(p) = \frac{125}{6} - \frac{4p}{3}$$

求解得到

$$q^{*} = 11.5, \qquad p^{*} = 7$$

換句話說，均衡集 $E$ 包含有序對 $(11.5,\; 7)$。

為什麼這裡用交集？

均衡的意思是「買方想買的量」與「賣方想賣的量」相等，且雙方對價格的接受度一致——也就是同時滿足需求關係與供給關係。用集合語言說，就是落在兩個集合的交集裡。

07

函數（Functions）

定義域、對應域、值域、反函數與合成函數。

定義 · 函數

設 $A$ 與 $B$ 為任意集合。一個從 $A$ 到 $B$ 的函數 $f$，把 $A$ 的每一個成員對應到 $B$ 中恰好一個成員。

  • $A$ 稱為定義域（domain）。
  • $B$ 稱為對應域（codomain）。
  • 值域（range，或稱 image）是函數實際取到的所有值所形成的集合。

啞變數（dummy variable）

例如 $f(x) = 2x$ 與 $f(y) = 2y$、$f(t) = 2t$ 是同一個函數。函數中使用的變數名稱不影響函數本身——它只是「佔位」用的啞變數。

輸入$x$
函數$f$
輸出$f(x)$ 或 $y$

反函數（inverse function）

定義 · 反函數

反函數把輸入與輸出對調。若 $f$ 與 $g$ 互為反函數，則

$$y = f(x) \quad \text{if and only if} \quad g(y) = x$$
$$f = g^{-1}$$
EXAMPLE求反函數

設 $f(x) = 2x + 7$。令 $y = 2x + 7$，則

$$2x = y - 7, \qquad x = \frac{y - 7}{2}$$

因此

$$f^{-1}(y) = \frac{y - 7}{2}$$

合成函數（composite function）

定義 · 合成函數

合成函數是「一個函數接在另一個函數之後」：

$$(s \circ r)(x) = s\big(r(x)\big)$$

函數的次序有關係。一般而言：

$$s \circ r \neq r \circ s$$
EXAMPLE求合成函數

設 $r(x) = x^2 + 2$，$s(x) = x^3$。則合成函數

$$k(x) = (s \circ r)(x) = s\big(r(x)\big) = s\left(x^2 + 2\right) = \left(x^2 + 2\right)^3$$

恆等函數（identity function）

定義 · 恆等函數

恆等函數把每個值對應到它自己：

$$i(x) = x$$

函數與其反函數的合成，就是恆等函數：

$$g \circ f = f^{-1} \circ f = i$$
EXAMPLE驗證 $f^{-1} \circ f = i$

設 $f(x) = 2x$，且 $f^{-1} = g(x) = \dfrac{x}{2}$。則

$$f^{-1} \circ f = (g \circ f)(x) = g\big(f(x)\big) = g(2x) = \frac{2x}{2} = x = i(x)$$

同理，合成函數 $f \circ f^{-1}$ 也等於 $i(x)$。

二次方程與方程組

因式分解、公式解、判別式，還有用集合交集解方程組。

定義 · 二次方程

二次方程（quadratic equation）的形式為

$$ax^2 + bx + c = 0, \qquad a \neq 0$$

它的解（roots）就是滿足該方程式的 $x$ 值。

方法一：因式分解（factorization）

EXAMPLE用因式分解求解
$$x^2 - 5x + 6 = 0$$

分解後：

$$(x - 2)(x - 3) = 0$$

兩個根分別是

$$x_1 = 2 \qquad \text{和} \qquad x_2 = 3$$

方法二：二次公式（quadratic formula）

公式 · 二次公式

對 $ax^2 + bx + c = 0$（$a \neq 0$）：

$$x_{1}, x_{2} = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

公式怎麼來的？——配方法（completing the square）

先把整個方程除以 $a$：

$$x^2 + \frac{b}{a}x + \frac{c}{a} = 0$$

利用完全平方，把前兩項湊成平方：

$$\left(x + \frac{b}{2a}\right)^2 = x^2 + 2x\cdot\frac{b}{2a} + \left(\frac{b}{2a}\right)^2 = x^2 + \frac{b}{a}x + \frac{b^2}{4a^2}$$

所以

$$x^2 + \frac{b}{a}x + \frac{c}{a} = \left(x + \frac{b}{2a}\right)^2 - \frac{b^2}{4a^2} + \frac{c}{a} = 0$$

移項整理：

$$\left(x + \frac{b}{2a}\right)^2 = \frac{b^2}{4a^2} - \frac{c}{a} = \frac{b^2 - 4ac}{4a^2}$$

兩邊開方：

$$x + \frac{b}{2a} = \pm\frac{\sqrt{b^2 - 4ac}}{2a}$$

於是

$$x_1 = \frac{-b + \sqrt{b^2 - 4ac}}{2a}, \qquad x_2 = \frac{-b - \sqrt{b^2 - 4ac}}{2a}$$

判別式：根有幾個？

判別式 $b^2 - 4ac$ 與根的數目
情況實數解的數目解
$b^2 - 4ac < 0$沒有實數解—
$b^2 - 4ac = 0$恰好一個解$x = -\dfrac{b}{2a}$
$b^2 - 4ac > 0$兩個解$x_{1,2} = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}$

用集合交集解方程組

集合的概念也可以用在函數上。考慮兩個集合：

$$G = \{\,(x, y) \mid y = x^2 - 5x + 6\,\}, \qquad L = \{\,(x, y) \mid y = 2x - 6\,\}$$

交集 $G \cap L$ 包含同時滿足兩條方程式的所有有序對——也就是這兩個圖形的交點。

EXAMPLE求 $G \cap L$

先消去 $y$：

$$x^2 - 5x + 6 = 2x - 6$$
$$x^2 - 7x + 12 = 0$$

因式分解：

$$(x - 3)(x - 4) = 0$$

所以 $x_1 = 3$、$x_2 = 4$。把這兩個值代回 $y = 2x - 6$，得到有序對 $(3, 0)$ 與 $(4, 2)$。因此

$$G \cap L = \{(3, 0),\; (4, 2)\}$$
本課重點
  • 集合是後面所有內容的基礎語言：$\in$、$\subseteq$、$\cup$、$\cap$、$\varnothing$。
  • 經濟學裡的「可行選項」與「均衡」都可以寫成集合，均衡就是交集。
  • 函數＝定義域到對應域的對應；反函數把輸出輸入對調；合成函數次序不能交換。
  • 二次方程的根由判別式 $b^2 - 4ac$ 決定個數。
