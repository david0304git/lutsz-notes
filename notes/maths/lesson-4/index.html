01

什麼是最佳化

經濟學幾乎所有問題都可以寫成「在某個限制下讓某個東西最大或最小」。

經濟學裡我們經常處理兩類問題：

  • 極大化（maximization）：廠商的利潤、消費者的效用、廠商或國家的成長率。
  • 極小化（minimization）：廠商的成本、消費者的支出。

在數學上，這意味著我們要找一組選擇變數（choice variables）的值，使目標函數（objective function）達到極值。

EXAMPLE廠商的利潤極大問題

假設廠商有成本函數 $C$，生產 $q$ 單位必須支付 $C(q)$。

產品可以每單位 $P(q)$ 的價格賣出，因此廠商的收入為

$$R(q) = qP(q)$$

顯然廠商的目標是選擇產量水準來極大化利潤：

$$\Pi(q) = R(q) - C(q)$$
目標函數（objective function）$\Pi(q)$
選擇變數（choice variable）$q$

「目標函數／選擇變數」這個區分很重要：先把哪個是目標、哪個是你能調的變數分清楚，後面的微分才有對象。

02

導數即斜率

幾何上，微分就是曲線在某一點切線的斜率。

  • 若 $f'(c) > 0$，切線在 $x = c$ 有正斜率。
  • 若 $f'(c) < 0$，切線在 $x = c$ 有負斜率。
  • 若 $f'(c) = 0$，切線是水平的。

切線近似了「$x$ 從 $c$ 小幅變動時，$y$ 的變化」。換句話說：$f'(c)$ 的正負，直接告訴我們函數在該點是上升還是下降。

$f'(c) = 0$：切線水平$\Longrightarrow$ 極值候選點
$f'(c) > 0$：切線正斜率$\Delta x > 0 \Rightarrow \Delta y > 0$；$\Delta x < 0 \Rightarrow \Delta y < 0$
$f'(c) < 0$：切線負斜率$\Delta x > 0 \Rightarrow \Delta y < 0$；$\Delta x < 0 \Rightarrow \Delta y > 0$
EXAMPLE從導數走向最佳化

假設某廠商的成本函數為 $C(q) = 9 + 5q$，價格函數（反需求函數）為 $P(q) = 6 - 0.01q$。

廠商的目標是選擇產量水準來極大化利潤：

$$\Pi(q) = R(q) - C(q) = q(6 - 0.01q) - (9 + 5q)$$
$$\Pi(q) = -9 + q - 0.01q^{2}$$

在利潤函數的最高點，切線與水平軸平行，因此斜率為零：

$$\Pi'(q_m) = 0$$

這給了我們利潤函數的駐點（stationary point）。

03

臨界點（駐點）

找極值的第一步永遠一樣：令一階導數為零。

定義 · 臨界點／駐點

一般而言，當我們要找極大值或極小值時，首先找斜率為零的點：

$$f' = 0$$

這些點稱為駐點（stationary points）或臨界點（critical points），是極值的候選點。

注意「候選」兩個字：$f' = 0$ 只保證切線水平，不保證那裡是極大或極小——下面就要從圖形看各種可能。

04

局部與全域極值

「附近最高」和「全場最高」是兩件事。

定義 · 嚴格遞增／嚴格遞減

函數嚴格遞增（strictly increasing）：若 $x_2 > x_1$，則 $f(x_2) > f(x_1)$。

函數嚴格遞減（strictly decreasing）：若 $x_2 > x_1$，則 $f(x_2) < f(x_1)$。

嚴格遞增函數有全域最小值，但沒有有限的最大值
嚴格遞減函數有全域最大值，但沒有有限的最小值

當定義域限制在閉區間 $x \in [a, b]$ 上時，函數可能同時具有：

  • 全域最大值（global maximum）與全域最小值（global minimum）
  • 若干個局部最大值（local maximum）與局部最小值（local minimum）
  • 以及既非極大也非極小的反曲點（inflection point）

局部極值只看「附近的鄰居」，全域極值看整個定義域。同一個函數可以有很多局部極大，但全域最大只有一個（值唯一）。

05

臨界點的三種類型

關鍵在一階導數通過該點時「正負號有沒有換、怎麼換」。

類型一 · 局部極大（local maximum）

若函數 $f(x)$ 在 $x = c$ 的一階導數為零（$f'(c) = 0$），且 $f'(x)$ 從 $c$ 的左側到右側由正轉負，則 $f(c)$ 是一個局部極大值。

$c$ 的左側$f'(x) > 0$（上升）
$c$ 的右側$f'(x) < 0$（下降）
類型二 · 局部極小（local minimum）

若 $f'(c) = 0$，且 $f'(x)$ 從 $c$ 的左側到右側由負轉正，則 $f(c)$ 是一個局部極小值。

$c$ 的左側$f'(x) < 0$（下降）
$c$ 的右側$f'(x) > 0$（上升）
類型三 · 反曲點（inflection point）

若 $f'(c) = 0$，且 $f'(x)$ 在 $c$ 的兩側同號，則該點既不是局部極大也不是局部極小。若凹凸性也在 $c$ 改變，它就是一個反曲點。

$c$ 的左側$f'(x) > 0$
$c$ 的右側$f'(x) > 0$（兩側同為正）
EXAMPLE找臨界點並判斷類型（用符號變化）

求函數 $f(x) = x^{3} - 12x^{2} + 21x + 100$ 的臨界點。

先求 $f'(x)$，並令 $f'(x) = 0$ 得到臨界值（駐點）：

$$f'(x) = 3x^{2} - 24x + 21 = 0$$
$$3(x - 1)(x - 7) = 0$$
$$x_1 = 1 \quad \text{and} \quad x_2 = 7$$

代入原函數求對應的函數值：當 $x_1 = 1$ 時 $f'(1) = 0$ 且 $f(1) = 110$；當 $x_2 = 7$ 時 $f'(7) = 0$ 且 $f(7) = 2$。

再看一階導數的符號分布：

$x < 1$$f'(x) > 0$
$1 < x < 7$$f'(x) < 0$
$x > 7$$f'(x) > 0$

因此：

$$f(1) = 110 \text{ 是局部極大}, \qquad f(7) = 2 \text{ 是局部極小}$$
06

二階導數的意義

一階導數是變化率；二階導數是變化率的變化率。

上一課介紹了高階導數，現在討論它的含義。

我們已知微分給出變化率，$f'(x)$ 衡量 $f(x)$ 的變化率。而 $f''(x)$ 衡量 $f'(x)$ 的變化率——換句話說，$f''(x)$ 衡量 $f(x)$ 變化率的變化率。

二階導數的符號

二階導數在 $c$ 的符號，告訴我們曲線的斜率如何變化：

$f''(c) > 0$斜率在 $c$ 正在遞增
$f''(c) < 0$斜率在 $c$ 正在遞減
注意 $f''$ 講的不是「函數在上升還是下降」，而是「斜率本身在變大還是變小」。下降中的函數也可以有 $f'' > 0$——只要它下降得越來越慢。
07

凹凸性與經濟例子

在曲線上任取兩點連一條直線，這條線在曲線上方還是下方，決定了凹凸。

定義 · 凸函數（convex function）

在曲線上任取兩點並用直線連接：

  • 若這條線段完全在曲線上方（除了那兩點），稱 $f$ 為嚴格凸函數（strictly convex）：$f''(x) > 0$。
  • 若這條線段完全在曲線上方或沿著曲線，稱 $f$ 為凸函數（convex）：$f''(x) \geq 0$。
定義 · 凹函數（concave function）

同樣取兩點連線：

  • 若線段完全在曲線下方（除了那兩點），稱 $f$ 為嚴格凹函數（strictly concave）：$f''(x) < 0$。
  • 若線段完全在曲線下方或沿著曲線，稱 $f$ 為凹函數（concave）：$f''(x) \leq 0$。
四種組合的經濟意義
符號圖形意義經濟例子
$f' > 0$、$f'' > 0$ 切線斜率隨 $x$ 遞增（$\Delta x$ 固定時，$y$ 的增量變大） 總成本函數：成本以遞增的速度上升，因為邊際成本為正（$C'(q) > 0$）且在上升（$C''(q) > 0$）
$f' < 0$、$f'' > 0$ 切線斜率隨 $x$ 遞增（$\Delta x$ 固定時，$y$ 的減量變小） 平均成本函數（U 形 AC 曲線下降段）：平均成本遞減（$AC'(q) < 0$），但以遞減的速度下降（$AC''(q) > 0$），逐漸逼近最低點
$f' > 0$、$f'' < 0$ 切線斜率隨 $x$ 遞減（$\Delta x$ 固定時，$y$ 的增量變小） 總產量函數：產出以遞減的速度上升，因為邊際產量為正（$TP'(L) = MP_L > 0$）且在下降（$TP''(L) = MP_L'(L) < 0$）——這就是邊際產量遞減
$f' < 0$、$f'' < 0$ 切線斜率隨 $x$ 遞減（$\Delta x$ 固定時，$y$ 的減量變大） 利潤函數（凹的利潤函數、超過利潤極大產量之後）：利潤遞減（$\Pi'(q) < 0$），而且以遞增的速度遞減（$\Pi''(q) < 0$）

記法：凹（concave）＝像山丘、$f'' < 0$，適合找極大；凸（convex）＝像山谷、$f'' > 0$，適合找極小。

08

二階導數與最佳化

把 $f'$ 與 $f''$ 的符號放在同一張圖上，極值的位置就很清楚了。

局部極大附近

在極大點的左邊函數上升、右邊下降，而整段斜率都在遞減，所以：

極大點左側（例如 $a$）$f'(a) > 0$，$f''(a) < 0$
極大點本身（例如 $b$）$f'(b) = 0$，$f''(b) < 0$
極大點右側（例如 $c$）$f'(c) < 0$，$f''(c) < 0$

局部極小附近

在極小點的左邊函數下降、右邊上升，整段斜率都在遞增，所以：

極小點左側（例如 $d$）$f'(d) < 0$，$f''(d) > 0$
極小點本身（例如 $e$）$f'(e) = 0$，$f''(e) > 0$
極小點右側（例如 $f$）$f'(f) > 0$，$f''(f) > 0$
看出來了嗎

關鍵組合只有兩種：

$f'(c) = 0$ 且 $f''(c) < 0$$\Longrightarrow$ 局部極大
$f'(c) = 0$ 且 $f''(c) > 0$$\Longrightarrow$ 局部極小
09

一階與二階條件

「必要」與「充分」的分工：一階條件找候選人，二階條件做決定。

一階條件（First-Order Condition）

$f'(c) = 0$ 確保函數的斜率為零。這是二階導數檢定中的必要條件。

$$f'(c) = 0$$
二階條件（Second-Order Condition）

找到滿足 $f'(c) = 0$ 的臨界點（駐點）之後，$f''(c)$ 的負號（正號）足以確立該駐點是局部極大（極小）。

$$f''(c) < 0 \Rightarrow \text{局部極大}, \qquad f''(c) > 0 \Rightarrow \text{局部極小}$$

一個滿足一階條件的駐點，可能既不是局部極大也不是局部極小——它可能是反曲點。

EXAMPLE完整跑一次二階導數檢定

求函數 $f(x) = x^{3} - 12x^{2} + 21x + 100$ 的臨界點。

一階條件：令 $f'(x) = 0$，得到臨界值（駐點）

$$f'(x) = 3x^{2} - 24x + 21 = 0 \quad\Longrightarrow\quad x_1 = 1 \text{ and } x_2 = 7$$

二階條件：求 $f''(x)$，判斷駐點是極大、極小，或檢定無結論

$$f''(x) = 6x - 24$$

當 $x_1 = 1$：$f''(1) = 6(1) - 24 = -18 < 0$，是極大。

當 $x_2 = 7$：$f''(7) = 6(7) - 24 = 18 > 0$，是極小。

與前面「看一階導數符號變化」得到相同的結論——但這次只要代兩個數字。

10

經濟應用：邊際成本與平均成本

為什麼 MC 曲線一定會穿過 AC 曲線的最低點？用商法則就能證明。

設 $C = C(q)$ 是生產 $q$ 單位產出的總成本。

定義 · 平均成本與邊際成本

平均成本（Average Cost, $AC$）是每單位產出的成本：

$$AC = \frac{C(q)}{q}$$

邊際成本（Marginal Cost, $MC$）可解釋為多生產一單位產出時總成本的近似變化：

$$MC = \frac{dC(q)}{dq} = C'(q)$$

回想一個直覺：如果多生產一單位的邊際成本低於目前平均成本（$MC < AC$），這一單位會把平均成本拉低。

$MC < AC$$AC$ 下降
$MC > AC$$AC$ 上升

用商法則把它導出來

由於 $AC = \dfrac{C(q)}{q}$，對 $q$ 微分（用商法則）：

$$AC' = \frac{C'(q)\,q - C(q)}{q^{2}}$$

代入 $MC = C'(q)$，並注意 $C(q) = AC \times q$：

$$AC' = \frac{MC \times q - C(q)}{q^{2}} = \frac{MC \times q - AC \times q}{q^{2}} = \frac{MC - AC}{q}$$
關鍵結果
$$AC' = \frac{MC - AC}{q}$$

因為產量為正（$q > 0$），$AC'$ 的符號完全取決於 $MC$ 是否大於 $AC$（也就是 $MC$ 曲線在 $AC$ 曲線上方還是下方）：

  • 若 $MC < AC$，則 $AC' < 0$，$AC$ 遞減。
  • 若 $MC > AC$，則 $AC' > 0$，$AC$ 遞增。
  • 若 $MC = AC$，則 $AC' = 0$，$q^{*}$ 是 $AC$ 的極小點。

確認它真的是極小

再微分一次：

$$AC'' = \frac{(MC' - AC')\,q - (MC - AC)}{q^{2}}$$

在 $MC = AC$ 且 $AC' = 0$ 的駐點上：

$$AC'' = \frac{MC'}{q} > 0 \quad \text{if } MC' > 0$$

所以 $AC$ 在該點是局部極小。這也解釋了圖形上的標準結果：MC 曲線由下往上穿過 AC 曲線的最低點。

11

經濟應用：獨占廠商的利潤極大

把「最大化利潤」完整寫成一階條件 $\to$ 二階條件兩步來跑。

CASE 1獨占：利潤極大（單一臨界點）

某獨占廠商面對需求集 $D = \{(q, p) \mid q + 5p = 850\}$，成本函數為 $C(q) = 300 - 10q + q^{2}$。

由 $q + 5p = 850$ 解出 $p$：

$$p = \frac{850}{5} - \frac{q}{5}$$

反需求函數為

$$p^{D}(q) = 170 - 0.2q$$

總收入為 $R(q) = q\,p^{D}(q) = 170q - 0.2q^{2}$。利潤 $\Pi(q)$ 為

$$\Pi(q) = R(q) - C(q) = 170q - 0.2q^{2} - (300 - 10q + q^{2})$$
$$\Pi(q) = -300 + 180q - 1.2q^{2}$$

獨占廠商的利潤極大問題：

$$\max_{q}\; \Pi(q) = -300 + 180q - 1.2q^{2}$$

一階條件：令 $\Pi'(q) = 0$

$$\Pi'(q) = 180 - 2.4q = 0 \quad\Longrightarrow\quad q_m = 75$$

二階條件：求 $\Pi''(q)$

$$\Pi''(q) = -2.4 < 0 \quad \text{for all } q$$

因為二階導數處處為負，$q_m = 75$ 確定是極大。最大利潤為

$$\Pi(75) = -300 + 180(75) - 1.2(75)^{2} = 6450$$

所以獨占廠商每週生產 75 單位時利潤最大。

CASE 2獨占：兩個臨界點，該選哪一個？

某獨占廠商面對線性反需求函數 $p^{D}(q) = 500 - 5q$，成本函數為

$$C(q) = 500 + 2q^{3} - 80q^{2} + 1100q$$

總收入為 $R(q) = q\,p^{D}(q) = 500q - 5q^{2}$。利潤為

$$\Pi(q) = R(q) - C(q) = 500q - 5q^{2} - (500 + 2q^{3} - 80q^{2} + 1100q)$$
$$\Pi(q) = -500 - 600q + 75q^{2} - 2q^{3}$$

極大化問題：

$$\max_{q}\; \Pi(q) = -500 - 600q + 75q^{2} - 2q^{3}$$

一階條件：令 $\Pi'(q) = 0$

$$\Pi'(q) = -600 + 150q - 6q^{2} = 0$$
$$\Pi'(q) = -6(q - 5)(q - 20) = 0 \quad\Longrightarrow\quad q_1 = 5,\; q_2 = 20$$

兩個候選點——哪一個使利潤極大？

二階條件：求 $\Pi''(q)$

$$\Pi''(q) = 150 - 12q$$
當 $q_1 = 5$$\Pi''(q_1) = 150 - 12(5) = 90 > 0$（局部極小）
當 $q_2 = 20$$\Pi''(q_2) = 150 - 12(20) = -90 < 0$（局部極大）

所以獨占廠商在生產 20 單位時利潤最大，最大利潤為

$$\Pi(20) = -500 - 600(20) + 75(20)^{2} - 2(20)^{3} = 1500$$

這題的重點：$\Pi'(q) = 0$ 給了兩個答案，必須靠二階條件挑出正確的那個。

12

經濟應用：政府的稅收極大

稅率不是越高越好——拉佛曲線的兩邊。

考慮需求與供給函數：

$$q^{D}(p) = 40 - 5p, \qquad q^{S}(p) = \frac{15}{2}p - 10$$

均衡時 $q^{D}(p) = q^{S}(p)$：

$$40 - 5p = \frac{15}{2}p - 10 \quad\Longrightarrow\quad p^{*} = 4$$

初始均衡為 $p^{*} = 4$、$q^{*} = 20$。

課徵從量稅

假設政府對生產者課徵每單位 $T$ 的稅。消費者支付價格 $p$，但生產者實收 $p - T$。因此供給函數變成

$$q^{ST}(p^{T}) = \frac{15}{2}(p^{T} - T) - 10$$

新的均衡滿足

$$40 - 5p^{T} = \frac{15}{2}(p^{T} - T) - 10 \quad\Longrightarrow\quad p^{T} = 4 + \frac{3}{5}T$$

均衡數量則是

$$q^{T} = 40 - 5\left(4 + \frac{3}{5}T\right) = 20 - 3T$$

數量要非負，因此 $0 \leq T \leq \dfrac{20}{3}$。

所以均衡價格隨 $T$ 上升，均衡數量隨 $T$ 下降——稅會同時推高價格、壓低交易量。

政府的稅收為

$$R(T) = q^{T} \cdot T = (20 - 3T)T = 20T - 3T^{2}$$

稅收極大化

政府的稅收極大問題：

$$\max_{T}\; R(T) = 20T - 3T^{2}$$

一階條件：令 $R'(T) = 0$

$$R'(T) = 20 - 6T = 0 \quad\Longrightarrow\quad T_m = \frac{10}{3}$$

二階條件：求 $R''(T)$

$$R''(T) = -6 < 0 \quad \text{for all } T$$

因此稅收在 $T_m = \dfrac{10}{3}$ 時達到極大。在這個稅率下，均衡數量為

$$q^{T} = 20 - 3\left(\frac{10}{3}\right) = 10$$

政府最大稅收為

$$R(T_m) = T_m\,q^{T} = \left(\frac{10}{3}\right)(10) = \frac{100}{3}$$

稅率再往上加，交易量掉得比稅率漲得更多，總稅收反而減少。

13

經濟應用：完全競爭廠商

價格是給定的，廠商只能選數量——而「要不要留在市場」是另一個問題。

假設市場價格由外部決定為 $p_0$。若完全競爭廠商生產數量 $q$，其收入為

$$R(q) = qp_0$$

利潤為 $\Pi(q) = R(q) - C(q) = qp_0 - C(q)$。

有效率的完全競爭廠商選擇 $q_0$ 來極大化利潤：

$$\max_{q}\; \Pi(q) = qp_0 - C(q)$$

一階條件：令 $\Pi'(q) = 0$

完全競爭的關鍵條件
$$\Pi'(q) = p_0 - C'(q) = 0 \quad\Longrightarrow\quad MC(q) = C'(q) = p_0$$

$p_0$ 是常數，因為廠商是價格接受者，無法影響市場價格。廠商增產直到「多一單位的成本」等於「多一單位的收入」。

開業點（start-up point）

在開業點上，有效率的完全競爭廠商對於「生產」與「短期內停業」無差異：虧損等於固定成本。廠商選擇 $q_s$，使得

$$\Pi(q_s) = q_s p_0 - C(q_s) = -C(0)$$

由於一階條件給出 $C'(q) = p_0$，代入得

$$\Pi(q_s) = C'(q_s)\,q_s - C(q_s) = -C(0)$$
$$p_0 = C'(q_s) = \frac{C(q_s) - C(0)}{q_s}$$

其中 $C(q_s) - C(0)$ 是 $q = q_s$ 時的總變動成本（總成本扣掉固定成本），所以

$$p_0 = MC(q_s) = AVC(q_s)$$

損益兩平點（breakeven point）

下一個問題是：廠商留在市場的條件是什麼？也就是損益兩平點：

$$\Pi(q_b) = q_b p_0 - C(q_b) = 0$$

同樣代入 $C'(q) = p_0$：

$$\Pi(q_b) = C'(q_b)\,q_b - C(q_b) = 0$$
$$p_0 = C'(q_b) = \frac{C(q_b)}{q_b} \quad\Longrightarrow\quad p_0 = MC(q_b) = AC(q_b)$$
兩個點的對照
開業點$MC = AVC$，且平均變動成本的導數為零
損益兩平點$MC = AC$，且平均成本的導數為零
EXAMPLE算出兩個點

考慮一家有效率的完全競爭廠商，成本函數為

$$C(q) = 800 + 70q - 12q^{2} + q^{3}$$

廠商的利潤函數為 $\Pi(q) = qp_0 - (800 + 70q - 12q^{2} + q^{3})$。由於一階條件給出 $C'(q) = p_0$，可把利潤改寫成 $\Pi(q) = C'(q)\,q - C(q)$：

$$\Pi(q) = q(70 - 24q + 3q^{2}) - (800 + 70q - 12q^{2} + q^{3}) = -800 - 12q^{2} + 2q^{3}$$

求開業點：解 $\Pi(q) = -800$（也就是虧損等於固定成本 $C(0)$）

$$-800 - 12q^{2} + 2q^{3} = -800$$
$$2q^{2}(q - 6) = 0 \quad\Longrightarrow\quad q_s = 6$$

此時的價格為

$$p_0 = C'(6) = 70 - 24(6) + 3(6)^{2} = 34$$

求損益兩平點：解 $\Pi(q) = 0$

$$-800 - 12q^{2} + 2q^{3} = 0$$
$$2(10 - q)(40 + 4q + q^{2}) = 0 \quad\Longrightarrow\quad q_b = 10$$

因為 $q \geq 0$，$40 + 4q + q^{2}$ 必定為正，所以只有 $q = 10$ 這個解。

此時的價格為

$$p_0 = C'(10) = 70 - 24(10) + 3(10)^{2} = 130$$

區間上的最佳化

真實世界有容量限制——別忘了檢查端點。

到目前為止我們找的都是局部極大或極小。但在實務上，我們經常面對全域最佳化問題。

例如，若廠商受到產能限制，一個實際的利潤極大問題會是在某個區間上找 $\Pi(q)$ 的最大值，例如 $q \in [0, L]$，其中 $L$ 是廠商能生產的最大數量。

定理 · 有限區間上的極值

設 $f$ 是閉區間 $[u, v]$ 上的連續函數，且 $f'$ 與 $f''$ 在 $[u, v]$ 內都存在。則 $f$ 在 $[u, v]$ 上有全域極大點 $m$，且必為下列之一：

  • (i) $u < m < v$，$f'(m) = 0$ 且 $f''(m) \leq 0$；或
  • (ii) $m$ 是端點 $u$ 或 $v$ 之一。

同樣地，$f$ 有全域極小點 $n$，且必為下列之一：

  • (i) $u < n < v$，$f'(n) = 0$ 且 $f''(n) \geq 0$；或
  • (ii) $n$ 是端點 $u$ 或 $v$ 之一。
EXAMPLE在 $[0, 2]$ 上找最大值與最小值

求函數 $f(x) = x^{3} - 8x^{2} + 16x - 1$ 在區間 $[0, 2]$ 上的最大值與最小值。

先對 $x$ 微分找臨界點。

一階條件：令 $f'(x) = 0$

$$f'(x) = 3x^{2} - 16x + 16 = 0$$
$$(3x - 4)(x - 4) = 0 \quad\Longrightarrow\quad x_1 = \frac{4}{3}, \; x_2 = 4$$

$x_2 = 4$ 落在區間 $[0, 2]$ 之外，與本題無關，直接捨去。

二階條件：求 $f''(x)$ 判斷極大或極小

$$f''(x) = 6x - 16$$

當 $x = \dfrac{4}{3}$：$f''\!\left(\dfrac{4}{3}\right) = 6\left(\dfrac{4}{3}\right) - 16 = -\dfrac{24}{3} < 0$，是極大。

最後與端點比較：

$x = 0$$f(x) = -1$（全域最小）
$x = \dfrac{4}{3}$$f(x) = \dfrac{229}{27}$（全域最大）
$x = 2$$f(x) = 7$

無限區間

考慮無限區間，例如 $x \in [u, +\infty)$。

與封閉有界區間不同，連續函數在無限區間上不保證能取到全域最大值或最小值。例如 $f(x) = x$ 在 $[u, +\infty)$ 上有全域最小值在 $u$，但沒有全域最大值。

無限區間上的極值（若存在）

若全域最大值 $m$ 存在，則必為下列之一：

  • (i) $m > u$，$f'(m) = 0$ 且 $f''(m) \leq 0$；或
  • (ii) $m = u$。

若全域最小值 $m$ 存在，則必為下列之一：

  • (i) $m > u$，$f'(m) = 0$ 且 $f''(m) \geq 0$；或
  • (ii) $m = u$。
本課重點
  • 最佳化＝選擇變數讓目標函數取極值；利潤 $\Pi(q) = R(q) - C(q)$ 是最典型的例子。
  • 一階條件 $f'(c) = 0$ 是必要條件，只給出候選點（駐點）。
  • 二階條件：$f''(c) < 0$ 為局部極大，$f''(c) > 0$ 為局部極小；兩側同號則是反曲點。
  • 凹函數（$f'' < 0$）適合找極大，凸函數（$f'' > 0$）適合找極小；$f''$ 描述的是「斜率」的變化。
  • $AC' = \dfrac{MC - AC}{q}$：$MC < AC$ 時 $AC$ 下降，$MC = AC$ 時 $AC$ 達極小——MC 由下往上穿過 AC 最低點。
  • 獨占廠商：$MR = MC$ 決定產量，再用二階條件確認是極大（$\Pi'' < 0$）。
  • 稅收極大 $\max R(T) = 20T - 3T^{2}$ 得 $T_m = \dfrac{10}{3}$，最大稅收 $\dfrac{100}{3}$。
  • 完全競爭：開業點 $MC = AVC$、損益兩平點 $MC = AC$。
  • 在有限區間 $[u, v]$ 上求全域極值，務必與端點比較；無限區間則不保證極值存在。
